# Portfolio Website (Next.js + Tailwind)

A clean, responsive portfolio website built with Next.js App Router and Tailwind CSS.

## Pages
- `/` Home
- `/about`
- `/portfolio`
- `/portfolio/[slug]`
- `/contact`

## Tech
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
